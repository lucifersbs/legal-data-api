## Short Description

## Long Description

### Overview

The **Legal Data API** provides developers with instant access to essential legal information for building case management systems, legal research tools, and client intake applications. Our API delivers accurate statute of limitations data for all 50 US states and average settlement ranges for common personal injury cases.

Built specifically for **legal tech developers**, this API helps you create powerful applications for law firms without the complexity of legal research.

### What You Get

✅ **Statute of Limitations Data**
- All 50 US states + DC
- 4 major case types: Personal Injury, Property Damage, Wrongful Death, Medical Malpractice
- Years-based limitation periods
- Human-readable descriptions

✅ **Settlement Data**
- Average settlement ranges for 4 injury types
- Slip & Fall, Car Accidents, Medical Malpractice, Workplace Injuries
- Minimum, maximum, and median values
- Key factors affecting settlement amounts

✅ **Developer-Friendly**
- Clean REST API with JSON responses
- Comprehensive error messages
- Rate limiting and security built-in
- cURL, Python, JavaScript, and Node.js examples
